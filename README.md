# TalentLink

> Plataforma web de recrutamento desenvolvida para conectar candidatos e empresas em um processo seletivo centralizado.
O **TalentLink** é um projeto acadêmico desenvolvido com práticas ágeis baseadas em **Scrum** e gerenciamento visual por **Kanban**.
Seu objetivo é centralizar o processo de recrutamento, permitindo que empresas publiquem vagas e candidatos encontrem oportunidades compatíveis de forma simples, organizada e eficiente.

---

## 📌 Objetivo

Desenvolver uma plataforma digital que facilite a conexão entre empresas e candidatos, oferecendo recursos para:

- Publicação e gerenciamento de vagas;

- Busca de oportunidades profissionais;

- Candidatura online;

- Acompanhamento do processo seletivo;

- Centralização das informações de recrutamento.

O sistema busca reduzir a informalidade dos processos seletivos e melhorar a experiência de todos os usuários envolvidos.
